# F Prime GDS in Rust (work in progress)

A from-scratch re-implementation of the F Prime Ground Data System in Rust. This branch shares no history with the Python GDS; it lives here until it gets its own repository.

- [Requirements and architecture](docs/design/requirements-and-architecture.md): the approved baseline. Read it before changing anything.
- [Comparison with YAMCS](docs/design/yamcs-comparison.md): what was adopted from YAMCS and what was not.
- [fgds repl](docs/repl.md): an interactive prompt on a running GDS.
- [HANDOFF.md](HANDOFF.md): current state, decisions and next steps.
